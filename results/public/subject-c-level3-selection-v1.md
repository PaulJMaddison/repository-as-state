# Subject C Level-3 selection — Phase A

Item 65 Phase A selected an independent private Subject C under a frozen anti-cherry-picking protocol before any Subject-C task-model output existed.

The discovery protocol was frozen before deep history inspection. The declared discovery roots produced 22 candidate repositories. All 22 were inventoried before deep chain review; five satisfied the frozen eligibility criteria and 17 were excluded under those criteria.

The selected private repository won under the frozen selection rule because it contained three eligible naturally sequential, locally testable historical chains, compared with two for each other retained candidate. The repository identity and private historical commit details are intentionally withheld from the public record.

The selected Level-3 chain contains three dependent historical tasks. PRE/POST boundaries are recoverable; future-history isolation, neutral task contracts, hidden semantic verification, negative controls and alternate-valid controls were all assessed as feasible.

No P1 success pattern or P2 failure pattern was used to select the repository. No Subject-C task-solving model was invoked, no Subject-C model output was generated, no correctness adjudication occurred, no hidden verifier was run against model output, no candidate was modified by the experiment, and no execution lock was created.

The accepted Phase-A private package SHA-256 is `6b54c793b07c706362f82efa7a64dd59276b059dd12aa583b43e99f78aa26373`; repeated hashing and internal package bindings passed.

Item 65 remains active. This selection/design acceptance does not constitute a Level-3 experimental result and does not permit Item 66 to start.
