# Subject C Level-3 design — Phase A

The coordinator-accepted Subject C design is a three-task cross-repository replication with three independent repetitions and two matched session conditions, for 18 planned future task-model executions and nine matched task-by-repetition A/B units.

Condition A retains reasoning/session continuity across the three dependent tasks within each repetition. Condition B uses a fresh independent reasoning session for every task-by-repetition unit. Both conditions must receive the same canonical historical PRE state, disclosed task contract, model/runtime, tools, permissions, network policy and acceptance/verifier semantics.

Repetitions are replications, not retries. The design preserves no human rescue, no best-of-N and no quality retry. Resource telemetry remains separate from correctness. Full-block blindness and freezing all outputs before correctness adjudication are required.

Before any Subject-C experimental execution, the selected three-task chain must be converted into frozen neutral task contracts; semantic hidden verifiers must be implemented and qualified with negative and alternate-valid controls; implementation independence must be demonstrated; future-history/private-material isolation must be proven against the actual experimental identity; and the runtime, prompts, randomisation, blind mapping, retry rules and execution lock must be frozen and publicly bound.

No Subject-C task-solving model has yet run. This document is a design binding, not an experimental result. Item 65 remains active and Item 66 remains blocked.
