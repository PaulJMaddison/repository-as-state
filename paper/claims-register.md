## Hostile-audit rules

- The only upgraded controlled EMPIRICAL continuity claim is C35, and it is bounded to the three-task Subject-B P1 sample.
- Subject-B P1 does **not** establish equivalence, non-inferiority, universal repository sufficiency or a resource-cost advantage.
- P0 remains `MIXED_METHODOLOGY_AND_MODEL_FAILURE` and non-causally-interpretable for A/B correctness.
- Handoff Debt is adverse prior evidence and must not be minimised.
- Git-bound/repository memory and sequential coding evaluation are prior art.
- RRI is descriptive, not a causal estimator.
- The full-history quadratic curve is a stress model, not a commercial-agent baseline.
- Any future empirical upgrade must link protocol version, exact public-safe evidence, model/runtime manifest, task/verifier hashes, analysis code and exclusions.
