\begin{abstract}
Long-horizon software-engineering agents can retain conversational history, summaries, memory stores, execution state, and repository observations across tasks. This paper asks whether one part of that continuity can instead be externalised into the software project's authoritative durable state. \emph{Repository-as-State} (RaS) treats accepted repository state as the persistent programme object and allows high-capability reasoning processes to be terminated after validated engineering transitions. A later fresh reasoner reconstructs a task-relevant view from the accepted repository state and current task. We call a reasoning process \emph{disposable with respect to programme continuity} when replacing it after an accepted transition does not materially reduce subsequent correct continuation under matched model capability, task, tool environment, and durable state.

The contribution is deliberately narrower than repository-aware coding, Git-backed memory, durable workflow execution, or sequential software-agent evaluation, all of which have substantial prior art. Recent work also shows that repository-only takeover of \emph{interrupted} coding tasks can incur significant rediscovery cost relative to handoffs carrying predecessor context. RaS therefore focuses on a different intervention: disposal at \emph{accepted engineering boundaries}, where the predecessor's decision-relevant consequences should already have been externalised into project artefacts. We propose a matched persistent-history versus forced-reset evaluation, a structured reconstruction probe, semantic-state ablation, descriptive Repository Resumability Index (RRI), and explicit reconstruction-cost accounting. A simple full-history replay model has quadratic cumulative input under stated assumptions, but this is not a general model of persistent agents; caching, compaction, retrieval, bounded history, and provider-side state can make persistent context growth substantially smaller.

Controlled empirical evaluation has not yet been executed. The present manuscript contributes a narrowed architecture, causal target, falsification criteria, and preregistration-oriented experimental method. Its core empirical question is whether fresh reasoning after accepted transitions can preserve engineering outcomes closely enough, and at low enough rediscovery cost, to justify making high-capability reasoning disposable.
\end{abstract}
