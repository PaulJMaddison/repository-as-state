# P1 coordinator clarification 001 — SearchForCars corpus status

This clarification is recorded before any P1 experimental task-solving model
invocation.

A coordinator statement incorrectly implied that a first-draft P1
task-contract failure would invalidate SearchForCars and trigger an immediate
move to RoomBundle.

That implication is wrong.

SearchForCars and the WP04/WP05/WP06 accepted historical chain were already
established extensively before P0. P1 is a methodology-corrected follow-up on
that same chain.

The corrected interpretation is:

- SearchForCars subject/corpus validity remains established;
- P1 must correct task-spec/governing-verifier alignment for the same
  transitions;
- a failed first-draft task contract means the proposed P1 specification is
  incomplete or unfair and must be corrected from legitimate historical
  requirements;
- it does not automatically invalidate SearchForCars;
- RoomBundle remains a later replication subject, not an automatic fallback.

No P0 artefact is changed.

No P1 experimental agent has run.

This clarification changes only the coordinator interpretation of the P1
preparation gate.
